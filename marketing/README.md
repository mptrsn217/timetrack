# Moonglare brand kit

Everything for marketing Moonglare in one place. The app itself doesn't use this folder; it serves `public/`.

## Idea

Better days start with noticing how you spend them. Moonglare is built on three ideas:

1. **Reduce bad habits**
2. **Reinforce good habits**
3. **Understand where the time goes**, and what you could do better

Tone: calm, friendly and encouraging, never preachy.

## Logo

- Use `moonglare-logo.svg` on its own, with no box or border, on white, light blue-white (`#f3f7fb`) or navy (`#0d1620`).
- Leave clear space around it of at least half its width.
- Don't recolour, stretch, outline or add shadows.
- The app icon (`moonglare-app-icon.svg`) is only for places that need a filled square: phone home screens, the browser tab and app stores.

## Type

**Inter**: ExtraBold (800) for headlines with tight letter spacing (about −3%), Regular (400) for body text.
The app uses each device's system font (San Francisco on iPhone, Segoe UI on Windows), which looks nearly the same.
